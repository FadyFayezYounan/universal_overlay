# Changelog

## 1.0.0

- Initial release
- `UniversalOverlayTheme` widget with InheritedTheme pattern
- `UniversalOverlayThemeData` for holding all theme data
- `ToastThemeData` for toast styling
- `LoadingThemeData` for loading indicator styling
- `CustomOverlayThemeData` for custom overlay styling
- Shared enums: `OverlayPosition`, `DismissalType`, `ToastDisplayMode`, `LoadingStyle`, `StackDirection`
- Shared models: `BarrierConfig`, `StackConfig`
- `OverlayAnimationBuilder` typedef for custom animations
